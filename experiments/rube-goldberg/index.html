      How it works

      The run

      Every change re-runs the whole machine from the start, in a fraction of a second. Playback just reads that run, so rewinding and stepping frame by frame are exact. If a link fails, the chain panel says where and why.

      Moving things

      Click any part of the machine to select it, then drag the arrows. Use turn mode for the ski jump, the camera operator and the whale. The operator moves with the ski jump, and he has to stay close to the wall to feel the bump.
