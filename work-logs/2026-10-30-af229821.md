## Challenges and how we solved them
- **Horizontal-scroll lesson started on panel 3.**
  - Symptom: the track showed panel 3 before any scrolling.
  - Investigation: probed the iframe and walked the track's ancestors' layout styles.
  - Cause: Chrome's centring behaviour pushed the track's position (recorded in the session as a layout issue with the centred content).
  - Fix: changed the scroll-lesson layout, and the track now starts at panel 1. The pinned scrub lesson also works.
- **Ease curves lacked contrast.** Filled the curves and rechecked them in the screenshots.
- **Timeline strip picked up Draggable's internal `userSelect` tween.** Filtered out Draggable's internal set.
- **Chrome extension unavailable.** Used headless Chrome over CDP.

## Lessons learned
- Run the code in a sandboxed iframe and probe it over CDP. Site isolation made direct probing awkward, so an isolated world or a standalone stage document was needed.

- Check each page's real layout in screenshots, not only for error-free runs.
