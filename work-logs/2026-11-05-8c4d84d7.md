## Work done
- **`split-flap.js` (new):** the engine moved out of `index.html`. `DEFAULTS` holds the live homepage configuration. `SplitFlap.mount(host, overrides)` returns `seek`, `update`, `ready`, `duration` and `tracks`. Nothing animates by itself; the caller runs the clock. Added to the `.vercelignore` allowlist.
- **Easing model:** the old leaf maths is exactly quadratic in-out across a 180° turn, so it became the `gravity` ease. Two eases now exist: `flipEase` (leaf angle in one flip) and `spinEase` (spacing of flips across a module's run, default linear). Eases are a name (`linear`, `gravity`, `bounce`, `elastic`) or a cubic-bezier array, so a config stays plain JSON. An ease that passes 180° rebounds off the stop.
- **`seed` option:** null on the site (new schedule each load); fixed in the lab so replays match.
- **`index.html`:** inline engine replaced by a short clock. Controls dropdown added as the first item in `.nav__start`, also in `tinkering/index.html`.
- **`nav.js`:** handles every `.dropdown` (it only bound the first, which would have broken Work). Opening one closes the other.
- **`styles.css`:** `.sf*` sizes read CSS variables with the old values as fallbacks; `.dropdown--controls` styles added.
- **`tinkering/split-flap-lab/` (new, `index.html` and `lab.js`):** parameter panel with definitions and per-row reset, easing editor with Spin/Leaf switch, presets, draggable handles and number fields, transport, scrubbable per-letter tracks, speed, loop, keyboard shortcuts (Space, R, arrows), localStorage persistence, Copy config, Reset. No card in the Tinkering gallery; marked noindex.

## Challenges and how we solved them
- **Engine edge cases exposed by sliders:** negative modulo past two drum turns would give undefined characters; one-letter boards hit `Math.max()` of nothing; `samples = 1` divided by zero; min above max flips. All guarded in the engine.
- **Reduced motion showed blank tiles on the site:** the old code returned before loading the font. The new code waits for the font and then seeks to the end.
- **Controls menu rendered under the Work row on phones:** fixed with `z-index: 1` on the menu.
- **Chrome extension not connected:** tested with Python Playwright driving headless Chrome instead.

## Lessons learned
- At 55 ms per flip, leaf easing is barely visible at full speed. Spin easing is what changes the look, and slow playback is needed to judge the leaf.
- The curve editor shows approximate handles for `gravity` while the curve itself is exact. Dragging a handle swaps to the bezier approximation.
