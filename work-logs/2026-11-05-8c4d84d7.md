## Work done
- **`split-flap.js` (new):** the engine moved out of `index.html`. `DEFAULTS` holds the live homepage configuration. `SplitFlap.mount(host, overrides)` returns `seek`, `update`, `ready`, `duration` and `tracks`. Nothing animates by itself; the caller runs the clock. Added to the `.vercelignore` allowlist.
- **Easing model:** the old leaf maths is exactly quadratic in-out across a 180° turn, so it became the `gravity` ease. Two eases now exist: `flipEase` (leaf angle in one flip) and `spinEase` (spacing of flips across a module's run, default linear). Eases are a name (`linear`, `gravity`, `bounce`, `elastic`) or a cubic-bezier array, so a config stays plain JSON. An ease that passes 180° rebounds off the stop.
- **`seed` option:** null on the site (new schedule each load); fixed in the lab so replays match.
- **`index.html`:** inline engine replaced by a short clock. Controls dropdown added as the first item in `.nav__start`, also in `tinkering/index.html`.
- **`nav.js`:** handles every `.dropdown` (it only bound the first, which would have broken Work). Opening one closes the other.
- **`styles.css`:** `.sf*` sizes read CSS variables with the old values as fallbacks; `.dropdown--controls` styles added.
- **`tinkering/split-flap-lab/` (new, `index.html` and `lab.js`):** parameter panel (about 30 parameters, each with a one-line definition and a per-row reset; changed values turn amber), easing editor with Spin/Leaf switch, presets, draggable handles and number fields, transport (play, pause, rewind plays backward, restart), scrubbable per-letter tracks, speed down to 0.03×, loop, keyboard shortcuts (Space, R, arrows), localStorage persistence, Copy config, Reset. ### Lab follow-ups
- **Space:** a capture-phase key handler toggles play and pause from any focus except text fields, and swallows the keyup so a focused button doesn't also click.
- **Versions:** `split-flap-versions.js` (new, in the `.vercelignore` allowlist) holds `{ active, versions }`. The homepage calls `SplitFlap.mount(heading, SplitFlap.activeConfig())`. The lab reads the file with a no-store fetch and writes it through the File System Access API. The handle persists in IndexedDB, so the picker appears once (permission may be re-asked on a later visit). Browsers without that API (Safari) get a download. Versions store overrides against `DEFAULTS` in `config`, plus lab-only `seed` and `stageColor` in `lab`. Seeded with Original (active, empty config) and Framed. The panel has a Versions section with Save, Load, Set active and Delete, and the header counts changes against the active version.
- **Grid:** engine options `padX`, `padY`, `fillRows`, `blankFlips`. `DEFAULTS` leaves them off, so the site changes only through an active version. The lab starts from `LAB_START` (padded, 12×4 = 48 cells, 840px wide, grain, framed). The last letter, not the last cell, still lands last. The timeline shows letters only (total time still includes blank cells). `fitBoard()` in the lab shrinks the board to the stage height. Empty cells flip and land blank; an "Empty cells flip" toggle turns that off.
- **Grain:** `grain` and `grainSize`, a tileable noise pattern baked into each cached tile over the glyph, so it swings with the leaf at no per-frame cost.
- **Frame:** `frame` plus `frameColor`, `wellColor`, `framePad`, `frameGap`, `frameInset`, `frameDepth`, `frameLip`, `frameSheen`. Plate and recess shading are CSS (`.is-framed` in `styles.css`) over the canvases; `.sf` clips leaves so they swing behind the plate. Tile size comes from `--sf-inset`. Flat / Framed switch in the lab header. `frameGap` is separate from Gap so each mode keeps its own spacing.
- **Font:** confirmed the tiles and lab use self-hosted `fonts/Geist-Variable.woff2` (weight 800 on tiles); the board waits for it before drawing, and the Weight slider gives true weights 100–900.

## Challenges and how we solved them
- **Engine edge cases exposed by sliders:** negative modulo past two drum turns would give undefined characters; one-letter boards hit `Math.max()` of nothing; `samples = 1` divided by zero; min above max flips. All guarded in the engine.
- **Reduced motion showed blank tiles on the site:** the old code returned before loading the font. The new code waits for the font and then seeks to the end.
- **Controls menu rendered under the Work row on phones:** fixed with `z-index: 1` on the menu.
- **Save hung silently:** a failed IndexedDB write threw inside a callback, so the promise never settled. The helper now rejects, and the error reaches the status line.
- **Grain too heavy:** 0.25 mottled the tiles and dirtied the letters; the lab default is 0.08.
- **Change counter wrapped in the panel header:** shortened to fit one line.
- **Chrome extension not connected:** tested with Python Playwright driving headless Chrome instead.

## Lessons learned
- At 55 ms per flip, leaf easing is barely visible at full speed. Spin easing is what changes the look, and slow playback is needed to judge the leaf.
- The curve editor shows approximate handles for `gravity` while the curve itself is exact. Dragging a handle swaps to the bezier approximation.
- A static site can't change itself from a browser, so versions must live in a repo file and go live only by commit and deploy.
- The user's reference board has much smaller, thinner letters inside each tile; lowering Glyph Size and Weight would get closer (left unchanged to preserve the name's current look).
