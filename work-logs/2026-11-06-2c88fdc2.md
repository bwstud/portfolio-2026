## Work done
- **`tools/lab-server.mjs` (new, no dependencies):** static server plus `GET`/`POST /__lab/versions`, which reads and writes `split-flap-versions.js` atomically. It parses `.vercelignore`, so it serves only what ships. Dotfile path segments and links out of the site return 404. It supports byte ranges for video, sends `no-store`, binds to 127.0.0.1, and starts at 8080 (or `PORT`), moving up to 10 ports if taken.
- **Write protection:** the Host must be local, a POST needs a matching Origin and a JSON content type, the body is capped at 256 KB, and the store's shape is validated.
- **`package.json` (new):** a `dev` script, `node tools/lab-server.mjs --open`. `dvs` prefers a `dev` script, so `~/.zshrc` needed no change and the other Mac only has to pull.
- **`tinkering/split-flap-lab/lab.js` and `index.html`:** removed the picker, IndexedDB handle and download fallback. Added **Use on landing page**: if the panel matches a saved version it makes that active, otherwise it saves under the typed name and makes that active. Once the panel matches the active version the button reads On landing page and is disabled. Original can't be replaced or deleted. Without the API (the deployed lab) versions are read-only: only Load shows.
- **`split-flap-versions.js`:** the user saved `2x2` and `2x1_tune1` in the lab and set `2x1_tune1` active. Shipped in its own commit (36baef1) so it can be reverted separately.

## Challenges and how we solved them
- **`--no-dotfiles` doesn't block dotfiles:** the running server returned the real `.env.local` and `.git/config` (matched by size, contents not printed). It's a listing option. An earlier note that `dvs` blocked dotfiles was wrong. The new server fixes this for this project.
- **The versions file changed during the build:** the user was saving in the lab at the same time. Caught in `git diff --stat`, so all tests ran on a throwaway copy in the scratchpad, with a fake `.env.local`.
- **Stopping PID 55495 was denied by the permission system:** not worked around. The new server took 8081 instead.
- **Original still had Delete:** spotted in a panel screenshot after saying it was protected. Fixed and checked on the real lab.
