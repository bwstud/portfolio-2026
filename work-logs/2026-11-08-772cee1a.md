## Challenges and how we solved them
- **Screenshot colours were wrong.** The first palette came from sampling a pasted screenshot, which macOS colour management had shifted (orange #DA7D27 instead of #F18300). Fixed by reading each swatch's fill through the Figma MCP and checking the document profile was sRGB.
- **Figma access.** The connector needed `/mcp` sign-in, and the MCP can't see which file is open, so the user pasted the file link.
- **Halftone seams.** Growing rust dots past half the cell clipped them at the tile edges, leaving sharp dark triangles. Fixed with the print approach: dots grow until they nearly touch (coverage up to π/4), then the row switches to the new colour with holes of the old colour that shrink.
- **Band showed Night through the gaps.** Between Rust and Pine, the gaps in the early dot rows let the page background through. Fixed by adding `var(--band-from)` as the band's base layer.
- **Narrow screens overlapped the band.** The narrow-screen `.project { padding: 64px 16px }` rule overrode the extra top padding, so titles sat on the dots. Fixed with `.project.project--band` for the higher specificity.
- **Ochre and Teal text contrast.** Mist on Ochre is 1.36:1 and on Teal 3.09:1. Both sections use Night text instead (11.24:1 and 4.95:1).
- **Previewing below the fold.** The cover is `min-height: 100vh`, so headless screenshots never reached the sections. Built scratch previews with `<base href="http://localhost:8081/">` and the cover hidden. Söhne doesn't load in those previews (file:// origin), so they show fallback fonts.
