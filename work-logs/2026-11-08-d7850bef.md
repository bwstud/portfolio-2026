### Kaleidoscopes (`tinkering/kaleidoscopes/`)
- **Renderer (`scope.js`):** one WebGL 2 fragment shader. Two-mirror wedges fold each pixel by angle (180°/n). Three- and four-mirror cells (equilateral, 90-45-45, 90-60-30 and square) reflect the pixel across whichever mirror it's beyond until it lands inside the cell. The number of reflections darkens it ("light lost per reflection"), and the distance to the nearest mirror draws seams. Also: lens bulge, twist, colour fringing (three folds at slightly different scales), round or full-screen eyepiece, vignette, glass sheen, tube colour, and brightness, contrast, saturation, hue and tint. The picture is a mirrored-repeat texture with mipmaps, and videos are re-uploaded every frame. `pose()` works out the cell's turn, drift, view spin and breathing at time t, and the lab's overlay uses the same function.
- **Configurations (`configs.js`):** 28 settings in six sections (mirrors, object cell, motion, glass and mirrors, eyepiece, colour), defined once. The lab builds its controls from that list. Ten built-ins: classic, snowflake, rose window, mandala, tile floor, star chart, mosaic, whirlpool, prism and antique brass. `normalise()` clamps and fills saved settings, so old saves survive new settings. Saves go to `configs.json` through the local server (it ships, so everyone sees them), or to localStorage on the deployed site. A kaleidoscope can also travel in a link as `#c=<base64url JSON>`.
- **Main page (`index.html`, `app.js`):** full-window view with two strips: kaleidoscopes, as live-rendered round thumbnails of the current picture, and pictures, the 10 gallery images plus "Your photo or video" (file picker or drop anywhere). Drag slides the picture under the mirrors, shift-drag or a two-finger twist turns it, and the wheel or a pinch magnifies (`shared.js`). The other controls: Turning on and off, reset view, snapshot (PNG), record a clip (MediaRecorder, WebM or MP4, with the video's sound if it's on), full screen, hide controls, video play/pause and sound. Keys: ← → for kaleidoscopes, [ ] for pictures, Space, S, R, F and H. The current picture's credit and licence link sits in the dock. The eyepiece is centred in the space between the header and the dock (`scope.frame`).
- **Lab (`lab/index.html`, `lab/lab.js`):** its own page, linked from the main page header, the Tinkering page's Controls menu and the home page's Controls menu (Kaleidoscope Lab).
  - **Left:** configurations grouped as built in, in the project and in this browser, each with a thumbnail and a dot when there are unsaved changes. New and Duplicate.
  - **Centre:** live preview with gestures, motion on and off, restart, and a "What the mirrors see" inset that dims the picture outside the object cell and outlines the cell as it moves. Below it, a test-picture row of the gallery plus your own file.
  - **Right:** name, description, and every setting with its value and help. A changed setting gets a dot and an Undo, and each section has its own Undo. Settings that don't apply are hidden, such as the mirror angle for triangles.
  - **Save bar:** Save (own configurations only), Save as new (the only option for built-ins), Undo changes and Delete. The header has Open in Kaleidoscopes (a share link while there are unsaved changes), Copy link, Export and Import (JSON). It warns before discarding changes or leaving the page.
- **Server (`tools/lab-server.mjs`):** `/__kaleido/ping` and `POST /__kaleido/configs` validate the list (ids, names, values that are only numbers, colours or short names, same-origin, JSON) and write `configs.json` atomically. The startup banner lists Kaleidoscopes.

Also a peacock photo (Jatin Sindhu, CC BY-SA 4.0), red tulip fields (acediscovery, CC BY 4.0) and a Kashmir shawl motif (The Met, CC0). ## Challenges and how we solved them
- **Invoice in a shipped folder:** `fonts/` is on the Vercel allowlist, so committing or deploying the order folder would have published the invoice. The loose font files are byte-identical to the order's `WOFF2/` copies (checked with shasum), so only those were committed and the order folder is ignored by both git and Vercel.

- **Wikimedia rate limits:** the Commons search API returned HTTP 429 after a few queries, and thumbnails must use standard widths (1920 worked, 2000 was refused). The four blocked downloads were retried in the background 30 s apart. Searching stopped there, so the tenth image came from the Met's open-access API instead. The Met has retired its v1 search, so v1.1 was used, and objects were filtered by `isPublicDomain` one by one.
- **Licences:** NASA's Juno colour images are often CC BY-NC-SA (citizen-processed), so they weren't used. The Landsat Bahamas image was only 750 px wide and the ISS aurora frame was mostly grey cloud, so the shawl was chosen instead.
- **JPEG size:** sips ignored `formatOptions` and wrote 2 MB files. Pillow had to run from a scratch folder without `-I` to find its site-packages.
- **Eyepiece behind the dock:** the first screenshots showed the round view centred on the window, with its bottom third under the controls. The shader now takes a centre and size (`uCenter`, `uM`), and the main page computes the frame between the header and dock each frame (full window when controls are hidden).
- **Phone header:** at 375 px the last header button was clipped. The back link shrinks to an arrow and the buttons tighten, so the header ends at 367 px.
- **Testing (headless Chrome via Playwright, real lab server on port 8790):** all ten kaleidoscopes render as live thumbnails, and seven were screenshotted full size. Picture switching, drag and wheel, and the credit line were checked. In the lab: a built-in was edited, Save as new wrote `configs.json` through the server, an in-place save changed it again, the main page opened it with `?config=`, and the overlay showed. A generated WebM through the file picker played through the mirrors with changing frames. The phone layout doesn't scroll sideways. The only console error was the site-wide missing `/favicon.ico`. The test configuration was removed afterwards, so `configs.json` ships as `[]`.
- **Another session sent replacement code:** while this was being built, another Claude session sent its own `lab/index.html`, `lab.js` and gallery card. They weren't used. Its HTML used IDs its own script didn't, its font path was one level short, its save would have written the built-ins into the project file, and its card didn't match the gallery's markup.
