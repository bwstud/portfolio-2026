**Halftone renderer** (`halftone.js`, new)
- Draws each band onto a `<canvas class="halftone">` inside its section. The canvas is centred on the edge with the section above and reaches `height/2 + bleed` px either side. It sets `--halftone-reach`, `--halftone-above` and `--halftone-below`. The CSS gradient dots were removed, so without JavaScript the band is a straight edge.
- Method: every pixel finds its nearest dot centres on a screen (grids: offset, hex or square; shapes: round, square, diamond or line). Dot radii come from a sorted distance-to-nearest-dot table. With "one size per dot" on, each dot takes its size from the coverage at its own centre.
- Settings (`DEFAULTS`): height, start/end, curve, cell (density in rows in the lab), dotSize, grid, shape, perDot, angle, stretch, softness; wave, ragged edge, mottle, warp, sizeTop/sizeBottom, jitter, seed; animate (mottle strength wanders between mottleMin and mottleMax), flow, heaveAmp/heaveLen, rise, morph, chaos (Randomness, default 0.6), animPeriod, animFps (default 60).
- `renderer(canvas)` uses a WebGL2 fragment shader that ports the CPU maths, noise hash included. Falls back to the CPU `mask()` + `paint()` path (still band only) when WebGL2 is missing. `animate()` uses requestAnimationFrame capped at animFps.
- `mount(sections, cfg)` redraws on width change, animates only bands an IntersectionObserver reports as visible, pauses when the tab is hidden, and never animates under `prefers-reduced-motion`.

*Cursor effect* (`halftone.js`, `tinkering/halftone-lab/lab.js`)

## Lessons learned
- The user wants the band animating from the start, not delayed behind the board intro. A deferral that hides the problem isn't acceptable; fix the cost instead.
- The user judges motion by eye on the real page. Numeric checks (shifted-frame comparisons, raggedness over time) confirm direction and regularity, but the user's feedback decides.
- A global animated parameter produces visible cycles. Vary it by position too.
- Ambiguous wording like "symmetrical" should be confirmed before building a big style change; the user reverted a mirror-dot interpretation.
- Measure each animation on its own before combining or deferring. The expensive part was the board's motion blur.
- Spins that start from a shared state need explicit randomness or neighbours march together. Measure displayed characters, not pixel hashes.
- The user tunes the board in the Split-Flap Lab and saves over versions, which can undo performance defaults. Check `split-flap-versions.js` before shipping.
- The user tries features and removes them quickly (mirror dots, guided scroll). Keep new behaviour easy to strip out.
- Restart the dev server after changing `.vercelignore`; it reads the allowlist only at startup.
- A real-fluid solver is the wrong tool for a bounded band; shed vortex pairs read as smoke and stay local.
- Git repos don't belong in iCloud-synced folders (Desktop, Documents) when Optimize Mac Storage is on. If git hangs with no CPU, check `find . -flags +dataless`.
- Installers like `npx impeccable install` can write files into the current repo and global hooks into `~/.claude/settings.json`. Check `git status` and the hooks after running one.
- "Captions should be Söhne Mono" reads as a site-wide rule: captions share the pills' monospace face.
