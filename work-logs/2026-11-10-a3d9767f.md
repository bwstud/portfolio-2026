## Challenges and how we solved them

- **Restart button "stopped working"** (reported mid-session). Could not reproduce: headless Chrome at 1280 and 390px showed it on top and replaying the board. Asked the user for specifics (what happened, browser, real phone or responsive mode, hard refresh); no follow-up came, and it was not raised again.
- **Black halftone transitions in light mode.** Chrome reports `color-mix()` colours as `color(srgb …)` in 0–1, which `rgb()` parsed as near-black. Fixed in `rgb()`.
- **Headless Chrome won't go below ~500px wide.** Used a 390px iframe at first, then built a small CDP driver (`node` + WebSocket, `Emulation.setDeviceMetricsOverride`) in the scratchpad for phone-width screenshots and in-page measurements.
- **Off-centre tiles.** Measured: tile pixel size came from `clientWidth` (rounded; real cell 61.656px), so tiles were drawn ~0.3% small and stretched; cells sat at different sub-pixel offsets, so edges blurred differently per window. A first pass still left cells 122.125 device px wide because `aspect-ratio` recomputed width from height; fixed by giving `.sf` an explicit width too.
- **"Always above the dots."** The hard limit (374.5px) put "Recent Work" ~260px above the dots most of the time. A CPU simulation of the mask (480 frames over 4 minutes) found a real peak of 308px at 1600px wide (median 224), and 306px at 390px (95% under 240, median 187). That led to `peak()` at 80% noise for desktop and 75% of the peak on phones.
- **Lab save test touched the real versions file.** Backed up `split-flap-versions.js` first, saved and activated a "Light test" version through the UI, verified `activeLight`, then restored the file (git showed it unchanged).
- **Dev server needed a restart** for the lab-server change; it was not running at first, then was stopped and restarted without `--open`.
- **Light-mode screenshot capture landed partway down the page** on phone; retook as a plain viewport shot.

## Lessons learned

- The user iterates visually and fast: make the change, screenshot, give a short honest read, offer one or two alternatives, and don't wait for approval on small style tries.
- Measure before fixing layout bugs; the CDP driver plus `getBoundingClientRect` at multiple widths settled the tile question quickly.
- Inline custom properties set by `split-flap.js` (gap, frame pad) can't be overridden by CSS variables; override the real properties (`padding`, `gap`) instead.
- Theoretical bounds on noise-driven motion are far above reality; simulate.
- Don't push without being asked: Claude left 2c97fa1 unpushed until the user said "Ship here".
