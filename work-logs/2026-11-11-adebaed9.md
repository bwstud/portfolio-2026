## Lessons learned

- Headless Chrome `--window-size` can't go below ~500px wide; use an iframe wrapper to check true phone widths.
- The `--chip-*` and role tokens are unregistered custom properties, so `getComputedStyle(...).getPropertyValue` returns raw `color-mix(...)` text; paint onto an element and read its computed `color` for a real value.
- User preferences: design system public on the site but `noindex`; separate branch per feature, merged to `main` only on request; pushing `main` waits for an explicit yes (it deploys to production).
- When snapping to a scale, add a missing step (4px) rather than visibly moving things.
- Greyscaling UI chrome keeps lightness so contrast and selected state still read; keep colour only where it carries information.
- `ignore-value` hook suppressions are page-wide, so they can hide real problems of the same kind on that page.
- The user prefers restraint: one signature object (the board), small plain text around it, colour used sparingly. Gold accents and "now showing" labels were rejected; lighter flaps and no re-spin were preferred.
- Anything the lab saves should drive the landing page without extra steps (and the user wants lab controls for anything they tune, e.g. the fade).
- The user likes the chip nav and wanted it back on the new page.
- zsh doesn't word-split `set -- $var`; use explicit function arguments in loops.
- A canvas that paints the ground colour is opaque: moving later content up behind earlier content can cover it even when the dots look sparse. Check the section above after any change to the page end.
- The `download` attribute gives a same-origin file a different saved name, which avoids keeping two copies.
- User preferences seen tonight: rapid small visual iterations, one request at a time, tried in the browser as I go; exact pixel figures when they have one in mind ("68px", "42px", "200px"); playful hidden details on the board are welcome (kaomoji); the user tunes and saves board versions in the lab themselves, so never change the active version without being asked.
- Say when a request has a side effect (button width changing when a label moves, a click that also selects a row); the user responded to those notes.
