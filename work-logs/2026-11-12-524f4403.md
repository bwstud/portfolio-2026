## Challenges and how we solved them

- **Room rendered black.** The light-preview strand set's `glowCount` was undefined, so three point lights got NaN intensity. Found by scanning the scene for non-finite values; initialised to 0.
- **`?at=` broke the page.** `sun.js` called the date formatter before it was declared; moved the formatter up.
- **Trees looked like bottle brushes.** Added sub-laterals, an outer shell of rolled sprays, larger sprays, thicker card strokes and an MSAA composer target (bloom was also removing antialiasing).
- **Night room lit like day, trees washed out.** Lowered lamps, ambient, hemisphere and in-tree glow; raised the bloom threshold; darkened needle colors.
- **Sunbeam invisible.** Raised the sun and lowered the window fill so the patch shows.

- **Lighting lab, GLSL name clash:** my ACES helper `RRTAndODTFit` collided with three's own tone-mapping chunk in lesson 7's shader; renamed.
- **Lighting lab, path tracer API:** `setSceneAsync` needs a BVH worker; switched to `setScene`. The tracer needs the equirectangular HDR as `scene.environment`, not a PMREM.
- **Lighting lab, stale readouts:** a lesson still awaiting a load could write into the next lesson's panel; added an `alive` flag to the lesson context.

## Unsolved problems

- **Accounts are not live on Vercel.** No Upstash Redis store is attached to the project and no env vars are set; until then the deployed game will run guest-only (saves in the browser). Setting it up needs the user's go-ahead.
- **The Vercel Function is deployed but has no store.** `GET /api/xmas` on production returns 503 "Accounts are not set up on this server yet." (checked with curl). Signup, save and load were only tested through the local dev server.
- **Performance unmeasured.** The room tree is about 5,000–7,000 instanced sprays (roughly 0.6–0.9M triangles plus a shadow pass). Fine in headless Chrome on this Mac; not tried on a phone or a weak laptop.
- **Not tested on a real phone or by hand.** All checks were Playwright screenshots and scripted clicks (Chrome, 1440×900 and the iPhone 13 profile).
- **The lot trailer's painted sign is in capitals**, copied from the user's reference photo. It's 3D scene art, not UI text; flagged for the user.
- The 8.5 ft trees' toppers touch the 9 ft ceiling (the inspection warns about it). Ornaments that fall but don't break go straight back in the box rather than staying on the floor.

- **Lighting lab: solid glass renders black in three-gpu-pathtracer** (lesson 8) in headless Chrome on this Mac (Apple M5, ANGLE Metal). Correct under SwiftShader; thin-walled glass works; same with 0.0.23 and 0.0.27. Bisecting found that any tracer created while another was already running was fine in a test page, but neither a throwaway companion nor a separate canvas fixed the app. Workarounds reverted; lesson 8 got a solid/thin glass switch; noted in the README. Not checked in a headed browser.
- **Lighting lab: Blender scripts untested.** Blender isn't installed here; both scripts compile with Python but haven't run in Blender. The lab side of the live link was tested with a glb made by three's GLTFExporter.
- Lighting lab performance on phones unmeasured; the path-traced lessons are heavy.
