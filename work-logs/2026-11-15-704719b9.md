## Challenges and how we solved them
- **Dev server did not serve `bison.js`:** it reads the allowlist once at startup. Fix: stop and restart it (the "stopped" notice afterwards was the old server).
- **Blank work-page screenshot:** the first harness didn't render the page. Fix: wrote a small Chrome DevTools screenshot script (`shot.mjs`).
- **Horn detection by colour was wrong:** switched to tone-based detection of horn and eye.
- **Packing script naming clash** (`L` shadowed the light vector) stopped a rebuild; renamed to `SUN`.
- **Tops blowing out in the first lit render:** softened the tones, retuned defaults.
- **Bison off-centre on the work page:** was centred on the window rather than the column beside the rail; fixed with the column offset, then the shared project container.
- **Fable usage limit** hit once mid-task; the user resumed afterwards.

No snapshot had the file (the Time Machine snapshot predates it; unmounted afterwards); last fader values were recovered from Chrome's local storage log. Saved a memory never to restore or test-write the live `*-versions.js` files.
- **Bison-shaped wall at 2× overflowed the stage** and read as a rectangle; dropped to 1.4×, then the whole idea was reverted at the user's call.
- **Sheet dropped the second result line:** it copied only the first line of each field; changed to copy every line.
- **Misplaced film:** I put the Groom Lake film in the work-page hero by mistake; the user wanted it atop the project panel. Reverted the wall files and moved it.
- **Paper exports time out** when many run at once ("startDownload() timed out"); batches of about 12 with a retry worked. Several photos share names, so files were moved by node id straight after each batch.
- **zsh does not split a `$T` list** into arguments; used an array.
- **Removing the photo cut left the `layer` function deleted** and a doubled line; caught by reading the result before rendering.
- **`?leave=` did not freeze the cover's exit in headless capture,** so the dissolve was checked by timing math only.

## Lessons learned
- The dev server reads save routes and the deploy allowlist only at startup; restart it after adding either.
- Hand-drawn heads from photographs read as a bird's head; a modelled head fixed it. The model must live outside the deployed folders and be gitignored.
- Every lab uses Matte (recorded in `CLAUDE.md`), and every numeric control needs a typed field.
- The user judges by eye; much of this was only checked as stills, never in motion.
- Lab version files (`*-versions.js`) are live user data: never restore them from a backup, and test saving against a copy.
- A silhouette-shaped wall around the bison didn't work at the stage sizes we have; if revisited it needs a taller stage or a different idea than scaling the silhouette.
- Confirm where a new asset goes (hero vs. slide-in panel) before wiring it in; "hero video" was ambiguous.
- The user supplies copy as pasted text and wants it word for word; flag likely errors instead of silently fixing them (typos aside).
- Stock photography and presentation slides inside the product film did not suit the user's taste; the film stays product-only.
