## Challenges and how we solved them
- **fontTools couldn't read WOFF2** (no Brotli): scratch venv with `fonttools` and `brotli`.
- **Trial font file names are NFD on disk** (macOS), so globbing for "ö" missed them: normalised to NFC and mapped back in the server.
- **Chrome extension not connected:** checked with headless Chrome `--screenshot` instead; this is why the preview picker also takes address parameters.
- **Headless screenshots at 390px were clipped:** headless Chrome's window is at least 500px; treated as tooling artefact.
- **Clicking in headless Chrome:** small CDP scripts in the scratchpad (`bio/press.mjs`, `totop.mjs`) to press switches and time the scroll.
- **Version bump failed in zsh** (a variable isn't split into filenames): nothing was committed; branch cleaned up and the bump redone with a proper loop before the PR.
- **Work page screenshots caught mid-arrival with the work-in-progress notice dimming the page** (Outcome cards and hero fade): re-shot with the notice closed and a longer wait.
- **"Result" label lost its uppercase mono style** after being moved out of the field row: restored.
- **Switching back to `main` stopped during PR #40** because the pre-compaction hook had changed the work log after commit: checked PR state, restored the hook's log, corrected its status lines, committed and pushed as 326f5e0.

## Lessons learned
- Licensed vs trial fonts: inspect name/licence tables with fontTools before adding any font to a public site; only files from the order folder are licensed. Preview trial weights through the local tool instead.
- The user prefers precise, small steps and decides on shipping; he sets values by feel (type sizes, lerp) and wants tuners with typed fields.
- Matte elevation should be shown through light and shadow, head-on, not perspective.
- Bump the `matte.css?v=` query on every page whenever `matte.css` changes.
- The user changes his mind on layout quickly (Result → The Team → Outcome); confirm before dropping copy he supplied, and keep it recoverable.
- `split-flap-versions.js` is written by the Split-Flap Lab; never commit it unasked (it changes the home page board).
