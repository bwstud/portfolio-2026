**Trial-font preview tool (`tools/font-preview/serve.py`, local only).**
- A small Python server that serves the repo and injects into every HTML page `@font-face` rules for the trial Söhne Breit (Extraleicht–Extrafett, except 600) and Söhne Mono (all but 400) weights, read from the Klim Test fonts installed in `~/Library/Fonts` via `/__trial/<file>`. The licensed Breit 600 and Mono 400 stay as built.
- A fixed picker bottom-left with two selects (Söhne Breit, Söhne Mono: "As built" or 200–900). The choice sets `font-weight` on every element whose computed family is that font; it's remembered in `localStorage` and can be set in the address (`?breit=800&mono=500`, 250 = Extraleicht).
- Run: `python3 tools/font-preview/serve.py [port]` (default 8090), then http://127.0.0.1:8090/. `tools/` isn't on the `.vercelignore` allowlist, so neither the tool nor the trial fonts ship.
- Verified with headless Chrome screenshots of the Work page at Breit 250 and 800 with Mono 500: the "Overhauling a flagship…" heading and the mono nav labels change as expected.

## Challenges and how we solved them
- **fontTools couldn't read WOFF2** (no Brotli): made a scratch venv with `fonttools` and `brotli`.
- **Trial font file names are NFD on disk** (macOS), so globbing for "ö" missed them; normalised names to NFC and mapped back to the on-disk names in the server.
- **Chrome extension not connected:** checked the preview with headless Chrome `--screenshot` instead, which is why the address parameters were added.

## Unsolved problems
- Klim's trial fonts have a limited character set; characters outside it (curly quotes, "·") fall back in the preview. A limit of the trial files.
