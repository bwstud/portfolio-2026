## Challenges and how we solved them
- **Headless screenshots of a modified page:** temp copies of `bio.html` returned 404 from the local server on :8080 (it doesn't serve arbitrary new files), so switched photos couldn't be shot in the frame. Checked the WebPs on a contact sheet instead, and that they serve with 200.
- **Gun on a dark page:** a charcoal silhouette would vanish on Night, so it got a cream outer edge (the halo layer). Drawing the silhouette once and using it twice avoids cream seams where parts overlap.
- **BANG! legibility at 96px:** the flag is drawn larger relative to the gun than before; text set to 12.5 units so it fits the burst. Readable at 2× but small.
- **Merge blocked:** the auto-mode permission check refused `gh pr merge`; the user said "Merge" and it went through.

## Lessons learned
- The user wants period labels and gun styling to be playful (explicit reference given), which overrides the native "no cartoon imagery" default for this element.
- Bio layout overrides belong in `bio.html`, not `matte-page.css`, which How I Work shares.
