## Challenges and how we solved them
- **Headless screenshots of a modified page:** temp copies of `bio.html` returned 404 from the local server on :8080, so switched photos couldn't be shot in the frame. Checked the WebPs on a contact sheet instead, and that they serve with 200.
- **Gun on a dark page:** a charcoal silhouette would vanish on Night, so it got a cream outer edge. Drawing the silhouette once and using it twice avoids cream seams where parts overlap.
- **BANG! legibility at 96px:** the flag is drawn larger relative to the gun than before; text set to 12.5 units to fit the burst. Readable at 2× but small.
- **Merge blocked:** the auto-mode permission check refused `gh pr merge` chained with other commands; once the user said "Merge" it went through. Running the merge on its own also worked for PR #42.
- **Live check found nothing at first:** `curl` on brianwstudwell.com got a 308 to `www.`; checking `www.` with `-L` showed the deploy was live.
- **Bison head-on looked hollow:** flanks piled into a bright rim around a sparse, dark face. Fixed by weighting head-on sampling toward surfaces facing the camera. Also brightened beads, thinned the dust ring into a clearer band, raised the away-facing brightness floor and added a coat-contrast fader.
- **Blender output path:** bead files were written somewhere unexpected; moved them into place and fixed the script's output path.

## Lessons learned
- The user wants period labels and gun styling to be playful (explicit reference given), which overrides the native "no cartoon imagery" default for this element.
- Bio layout overrides belong in `bio.html`, not `matte-page.css`, which How I Work shares.
- For point-cloud portraits, sample by visible area per view, otherwise silhouettes dominate the face.
