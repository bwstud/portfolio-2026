## Challenges and how we solved them
- **Catch up crashed on load:** the movement had both a `predict` question and a `predict()` method; the method overwrote the data. Renamed to `forecast()`.
- **Hash links did nothing:** no `hashchange` handler; added.
- **Wedges and the ellipse read as a black disc:** the canvas was transparent over a CSS gradient, so additive geometry wrote alpha and punched opaque holes. The sky gradient now lives in WebGL (`scene.background`). Earlier, linear vertex colours had made the wedges far too bright.
- **No rosette in the rotating frame:** my physics error. A circular inner orbit seen turning with the outer moon is just a circle. The loops come from watching from the outer body without turning (epicycles), or from drawing the line between the bodies (the Venus rose). Added those viewpoints.
- **Transfer window unhittable:** 3 million km capture at 20 d/s gave about 0.08 s to press Burn. Skip now stops the clock at the window; an exact Hohmann graze counts.
- **Typed numbers re-rounded:** Enter then blur ran `tidy` twice on the rounded display. Fixed; the typed value is kept as typed.
- **Syntax error missed by `node --check`:** an unescaped apostrophe in a JS string. Plain `node --check` on `.js` in this non-module package didn't flag it; checks now copy each file to `.mjs` first.
- **Finale race:** the Transfer summary was read before it was set. Finales are now requested 700 ms after the last goal.
- **One burn docked:** the 2 m/s threshold let a single retrograde burn win; now under 0.5 m/s, so the matching burn is needed.
- **Venus rose turned to mesh:** sampling strings at 1/24 lap aliased; back to 1/40, capped at 520 (exactly one eight-year rose).
- **Finale fallback and one-burn dock** (R3), **post-arrival readouts rewritten by the fader** (R5): each was a state leak; fixed and added to scripted play's assertions (finale text, burn count, readouts after a stray `plan()`, marker visibility).
- **Shell heredocs blocked** by a safety parser twice (no deletion in them); scripts written with the file tool instead.
